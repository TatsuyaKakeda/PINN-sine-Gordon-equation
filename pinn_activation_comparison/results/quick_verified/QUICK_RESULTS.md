# Quick mode 検証結果

CPU・100 epoch・隠れ層4×幅64・seed 0, 1, 2で、tanh、SIREN、Gaussian γ=0/0.001/0.01/0.05の18実験を実行しました。Full mode は実行していません。

全18実験が100 epochまで完了し、NaN/Infや設定した発散停止しきい値の超過はありませんでした。ただし相対L2誤差はほぼ1であり、breatherを精度よく学習できた結果ではありません。目標誤差0.1に到達した実験は0件です。

数値は3 seedの平均 ± 標本標準偏差（ddof=1）。損失は最終更新後の全学習点、誤差・残差は81×81の独立した等間隔格子で評価しています。

| モデル | 相対L2誤差 | 最終Total loss | 評価PDE残差RMS | 学習時間 [s] |
| --- | ---: | ---: | ---: | ---: |
| tanh | 1.008 ± 0.00445 | 0.79916 ± 0.102 | 0.059467 ± 0.0266 | 0.27636 ± 0.0156 |
| SIREN | 0.99968 ± 0.00564 | 16.269 ± 13.8 | 3.6725 ± 2.4 | 0.36681 ± 0.00945 |
| Gaussian γ=0.0 | 0.99968 ± 0.00564 | 16.269 ± 13.8 | 3.6725 ± 2.4 | 0.3567 ± 0.013 |
| Gaussian γ=0.001 | 0.99303 ± 0.0139 | 0.57716 ± 0.693 | 0.72899 ± 0.378 | 0.63701 ± 0.0192 |
| Gaussian γ=0.01 | 0.98813 ± 0.0127 | 0.072033 ± 0.123 | 0.50706 ± 0.323 | 0.60685 ± 0.00668 |
| Gaussian γ=0.05 | 0.98212 ± 0.0062 | 0.16972 ± 0.179 | 0.33034 ± 0.0513 | 0.63466 ± 0.0459 |

学習時間はAdam更新・微分・診断・ミニバッチ選択・同期の時間です。準備、定期評価、保存、作図は除きます。18実験の学習時間合計は約8.64秒、最初の一括実行全体（初回作図を含む）は約25.02秒でした。短時間計測なので時計や実行順の揺れにも注意してください。

## 一致と保存の検証

- γ=0 と SIREN は、3 seedすべてで予測配列が完全一致しました。テストでは出力・一階/二階微分・初期重み・学習履歴・最終重みの一致も確認しています。
- 各実験のcheckpoint、100行の損失/勾配履歴、設定、評価値、予測配列を保存しました。共通学習点はseedごとのNPZにあります。
- 29枚のPNGを保存しました。ヒートマップは18実験を通して同一の場/誤差カラースケールを使っています。

## この段階で読めること

中心時系列とヒートマップでは、予測振幅が厳密解に比べて小さく、周期振動を十分に再現していません。Gaussian γ=0.05の平均相対L2誤差はこの短時間実験では最小でしたが、約0.98であり、実用的な精度や優位性の根拠にはなりません。Gaussian γ=0.01では最終損失が比較的小さくても相対L2誤差は約0.99でした。PDE/IC/BC損失の低下と解全体の精度を別々に評価する必要があります。

学習中の最大勾配ノルムのseed平均は、SIRENで約1.02×10^4、Gaussian γ=0.001で約588、γ=0.01で約298、γ=0.05で約119でした。この条件では包絡による勾配低下が観測されましたが、勾配消失の改善、解の局在性、高周波表現能力を保証する結果ではありません。全体がゼロに近い解も小さなPDE残差を取り得ます。

## 実行環境・再現

Python 3.13.5, PyTorch 2.14.1, NumPy 2.5.4, matplotlib 3.11.2, CPU 1 thread。MPSはこの実行環境では使用不可でした。MPSの実機二階微分は未検証で、フォールバックと全比較のCPU再実行は模擬エラーのテストで検証しています。

外部パッケージ取得がDNS制限で失敗したため、既存環境のインストール済みパッケージを作業内の仮想環境にコピーしました。元の環境は変更していません。使用版は [environment-lock.txt](environment-lock.txt)、学習時ソースとハッシュは `source/` と `experiment.json` にあります。

```bash
.venv/bin/python -m pinn_activation_comparison.train --mode quick --seed 0 1 2 --output-dir pinn_activation_comparison/results/quick_repeat
```
